# Voxa — مولد صوت بالذكاء الاصطناعي

صفحة هبوط ثنائية اللغة (عربية RTL وإنجليزية LTR) لمولد صوت بالذكاء الاصطناعي، مع مشغل عينات صوتية محاكى ودعم متعدد اللغات وحالات استخدام.

## التشغيل

```bash
npm install
npm run dev
npm run build
```

## المميزات

- ثنائي اللغة: عربية (RTL) وإنجليزية (LTR) مع مبدل لغة، والتفضيل محفوظ في localStorage.
- ملفات ترجمة: `locales/en/common.json` و `locales/ar/common.json`، ولا نصوص ثابتة مبعثرة في المكونات.
- أقسام الصفحة: تنقل، بطل، إثبات، مزايا، كيف يعمل، أمثلة تفاعلية، آراء عينة، أسعار (حيث تنطبق)، أسئلة شائعة، دعوة أخيرة، تذييل.
- قسم كشف الشعار (tagline reveal) مع حركة كلمة بكلمة.
- نموذج تسجيل مع تحقق من الاسم والبريد، ورسائل نجاح وخطأ واضحة.
- متجاوب من 320px إلى 1440px فأكثر، وفحص عدم تجاوز العرض عند 390px.
- خط Manrope فقط، بلا مائل، وبلا كلمات محظورة، وبلا أرقام أو أسعار مختلقة (الأسعار عناصر مؤقتة {{price}}).

## ملاحظات

- العرض التفاعلي محاكاة على جهاز المستخدم ولا يتصل بأي خدمة خارجية.
- آراء المستخدمين المعروضة عينات موسومة، وليست شهادات حقيقية.
